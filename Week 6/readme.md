# Week 6 – LLM Evaluation and Baseline Testing (Release v0.1)

## 1. Project Overview

In Week 6, we developed a basic LLM evaluation system using the **Llama 3.2 model through Ollama**.

The main objective of this practical is to evaluate the answers generated by a Large Language Model (LLM) using a predefined set of questions called a **Golden Question Set**.

The system compares the model's answers with expected answers by checking important keywords. It calculates a keyword coverage score and classifies each response as PASS, REVIEW, or ERROR.

Finally, the evaluation results are automatically saved in a CSV file, and the first experiment is officially recorded as **Release v0.1**.

## 2. Objectives

- Create a Golden Question Set with questions, expected answers, keywords, and source links.
- Run the Llama 3.2 model locally using Ollama.
- Generate answers for predefined questions.
- Evaluate generated answers using keyword-based scoring.
- Identify matched and missing keywords.
- Calculate the average keyword coverage.
- Save evaluation results in a CSV file.
- Create the first baseline evaluation as Release v0.1.

## 5. Concepts Used

### Golden Question Set

A Golden Question Set is a collection of questions with predefined expected answers, important keywords, and reference sources.

It is used to check whether an LLM generates relevant answers.

### LLM Evaluation

LLM evaluation is the process of checking the quality of answers generated by a language model.

In this practical, evaluation is performed using keyword matching.

### Keyword-Based Scoring

The program checks how many expected keywords are present in the generated answer.

**Formula:**

Score = (Matched Keywords / Total Expected Keywords) × 100

### PASS, REVIEW, and ERROR

- **PASS:** The keyword score is 60% or above.
- **REVIEW:** The keyword score is below 60%.
- **ERROR:** The model request or processing fails.

### Baseline Evaluation

A baseline evaluation is the first recorded performance of a model. It provides a reference point for comparing future model versions or improvements.

## 6. Implementation

### Step 1: Create the Project Folder

Create a folder named `week6` in VS Code.

Inside it, create:
- `main.py`
- `requirements.txt`
- `golden_set.json`

### Step 2: Set Up Ollama

Check whether Ollama is installed:

```bash
ollama --version
```

Download the Llama 3.2 model:

```bash
ollama pull llama3.2
```

### Step 3: Create the Golden Question Set

Create `golden_set.json` with 30 questions.

Each question contains:
- ID
- Question
- Expected answer
- Keywords
- Source URL

The questions cover topics such as tokenization, BPE, WordPiece, token economics, context windows, rate limits, autoregressive generation, sampling, embeddings, and positional encoding.

### Step 4: Install Dependencies

Add the following library to `requirements.txt`:

```text
requests
```

Install it using:

```bash
pip install -r requirements.txt
```

### Step 5: Run the Python Program

Execute the main program:

```bash
python main.py
```

The program sends all questions to the Llama 3.2 model through the Ollama API and evaluates the generated responses.

## 7. Working Process

1. Load the Golden Question Set from the JSON file.
2. Send each question to the Llama 3.2 model.
3. Receive the generated answer from Ollama.
4. Compare the answer with the expected keywords.
5. Identify matched and missing keywords.
6. Calculate the keyword coverage score.
7. Assign PASS, REVIEW, or ERROR status.
8. Save all results in `baseline_results.csv`.
9. Display the final evaluation summary.

## 8. Evaluation Output

The program generates the following information for every question:

- Question ID
- Original question
- Expected answer
- LLM-generated answer
- Matched keywords
- Missing keywords
- Score
- Status
- Source
- Model name
- Release version

At the end, it displays:
- Total questions
- Successful responses
- Passed questions
- Questions for review
- Failed requests
- Average keyword coverage
- Evaluation date

## 9. Output File
